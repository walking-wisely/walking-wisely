### 🔨 What I'm building

#### [Holy Blocker](https://github.com/walking-wisely/holy-blocker) — faith-motivated, privacy-first content blocker
A cross-platform content blocker that intercepts at two independent layers — a network path (TLS termination, packet filtering, perceptual image hashing) and a screen-capture path (on-device ONNX classifier, OCR) — so content is blocked before it renders *and* after, regardless of where it comes from. All decisions happen on-device. No data leaves the machine.

Built with Rust (text policy, MITM proxy, net-shield), C++20 (Windows daemon), Python (ML pipeline), and Electron for the control panel.

**Contributions welcome** — especially if you have experience with Windows networking, Rust async, or on-device ML. See [CONTRIBUTING.md](https://github.com/walking-wisely/holy-blocker/blob/main/CONTRIBUTING.md).

#### [Bible MCP](https://github.com/walking-wisely/bible-mcp) — semantic Bible search via embeddings
An MCP server that exposes scripture search through vector embeddings, making it usable as a context source for AI agents and tools.
